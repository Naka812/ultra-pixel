## Português

O **Ultra Pixel** é um editor de pixel art gratuito, feito para facilitar a vida de quem desenvolve jogos. Ele roda direto no navegador, sem instalar nada e sem criar conta.

> **Atenção:** o editor funciona somente no navegador de computador (PC). Ele não é compatível com celulares e tablets.

### Recursos

- Camadas
- Paletas de cores e harmonia de cores
- Animação com linha do tempo e onion skin
- Exportação de GIF
- Exportação de sprite sheet
- Interface em português e inglês
- Projetos salvos no próprio navegador

### Privacidade

Seus desenhos ficam guardados **somente no seu navegador**. Nada é enviado para um servidor. Isso significa que, se você limpar os dados do navegador, os projetos podem ser apagados, então exporte o que for importante.

### Rodar no seu computador

Você precisa do [Node.js](https://nodejs.org) (versão LTS).

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000/ultra-pixel/` no navegador.

## English

**Ultra Pixel** is a free pixel art editor made to make life easier for game developers. It runs right in your browser, with nothing to install and no account needed.

> **Note:** the editor works only in a desktop (PC) browser. It is not compatible with phones and tablets.

### Features

- Layers
- Color palettes and color harmony
- Timeline animation with onion skin
- GIF export
- Sprite sheet export
- Portuguese and English interface
- Projects saved in your own browser

### Privacy

Your artwork is stored **only in your browser**. Nothing is sent to a server. This means that if you clear your browser data, your projects may be deleted, so export anything important.

### Run it on your computer

You need [Node.js](https://nodejs.org) (LTS version).

```bash
npm install
npm run dev
```

Then open `http://localhost:3000/ultra-pixel/` in your browser.
